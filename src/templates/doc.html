🔧 Printer Setup Guide All Platforms

Linux (Ubuntu / Debian)

  1. Install CUPS: sudo apt install cups -y
  2. Start CUPS: sudo systemctl enable --now cups
  3. Add your printer via CUPS web UI: http://localhost:631
  4. Verify: lpstat -p -d should list your printer
  5. Test: echo "test" | lp

Windows

  1. Connect your printer normally (USB or network)
  2. Ensure the printer appears in Settings > Printers & Scanners
  3. No additional setup needed — pdf-to-printer handles everything

macOS

  1. CUPS is pre-installed on macOS
  2. Add your printer in System Preferences > Printers & Scanners
  3. Verify: lpstat -p -d should list your printer

Chromium (auto-installed)

Puppeteer downloads its own Chromium on npm install. No manual browser install needed.
